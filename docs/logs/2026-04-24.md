## Problems & Solutions

### MQTT Connection Crash on Startup

**Error:**
```
MQTTnet.Exceptions.MqttCommunicationException: Received an unexpected EOF or 0 bytes from the transport stream.
 ---> System.IO.IOException: Received an unexpected EOF or 0 bytes from the transport stream.
```

**Root Cause:**
`MqttSubscriberService.cs` unconditionally called `.WithTlsOptions(o => o.UseTls())`, but `appsettings.json` was configured with a local broker at port 1883 (plain TCP). TLS attempted a handshake against a non-TLS port, causing the SSL stream to receive an immediate EOF.

**Fix (`Services/MqttSubscriberService.cs`):**
Changed TLS to be conditional on the port — only enabled when port is 8883:

```csharp
var optionsBuilder = new MqttClientOptionsBuilder()
    .WithTcpServer(host, port)
    .WithCredentials(username, password);

if (port == 8883)
    optionsBuilder = optionsBuilder.WithTlsOptions(o => o.UseTls());

var options = optionsBuilder.Build();
```

**Rule:** Port 1883 = plain TCP, port 8883 = TLS. Update `appsettings.json` `Mqtt:Port` to switch between local dev (1883) and HiveMQ Cloud (8883).
